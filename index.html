Struktur Silabus Mata Kuliah Pemrograman Web

Mata kuliah ini akan membekali mahasiswa dengan kompetensi rekayasa aplikasi web modern. Berikut adalah pembagian materi pembelajaran:

  1. Sisi Klien (Front-End)
    • Modul 1: Fondasi Arsitektru Web & HTML5 Semantik
    • Modul 2: Standarisasi Kode & Pengorganisasian Konten
    • Modul 3: Rekayasa Media Digital & Dasar CSS
    • Modul 4: Tata Letak Grid, Flexbox, & Bootstrap
  2. Sisi Server (Back-End)
    • Modul 5: Pengantar Pemrograman Server
    • Modul 6: Database dan ORM
    • Modul 7: API dan Web Services
    • Modul 8: Keamanan Web
